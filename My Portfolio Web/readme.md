# MINOVA TECH - Personal Portfolio Website

A clean, modern, and minimalistic personal portfolio website built with pure **HTML5** and **CSS3**.

---

## 🎨 Theme & Design System
- **Color Palette**: Fresh Clean Light Trio with Royal Blue Framing
  - **Royal Blue (`#2563eb`) Header & Footer**: Distinctive brand frame with pure white text and navigation.
  - **Pure White (`#ffffff`) Page Body**: Clean canvas, high contrast, and effortless clarity.
  - **Deep Slate (`#0f172a`) Text**: Sharp, modern, and highly readable typography.
- **Typography**: Modern Google Font **Poppins** with clean weights (400, 500, 600, 700).
- **Design Philosophy**: High contrast, crisp 1px borders, solid colors, and **zero shadows**.

---

## 📌 Development Rules & Guidelines
1. **HTML & CSS Only**: Strictly pure HTML and CSS — no JavaScript.
2. **Step-by-Step Development**: Build one section/page at a time.
3. **Standalone Separate Pages**: Each page has its own dedicated content and its own footer.
4. **Preserve Working Code**: Never unnecessarily break working components.

---

## 🗺️ Project Development Roadmap
- [x] **Home Page (`home.html`)**: Focused hero presentation with elegant blue & white abstract tech background, clear CTAs, clean header, and footer.
- [x] **About Page (`about.html`)**: Brand story, motto ("We Design. We Build. We Grow."), and core pillars.
- [x] **Skills Page (`skill.html`)**: Technical toolkit with pure CSS progress bars.
- [x] **Portfolio Page (`portfolio.html`)**: 9 project showcase cards with preview images and tech tags.
- [x] **Contact Page (`contact.html`)**: Clean contact cards and HTML5 message form.
